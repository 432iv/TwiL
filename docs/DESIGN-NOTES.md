# ملاحظات التصميم — يوسف للعطور

الهوية: **بيج دافئ + بني قهوة ناعم + لمسات نحاسية خافتة** — هادئة وفاخرة بلا أزرق.
لا تغيير على بنية الصفحة (DOM) ولا مسارات الـ API لأجل الشكل؛ التغيير بصري فقط.

- الألوان في متغيرات CSS داخل `<style id="skin-v5">` ثم تُضبط الهوية النهائية في `<style id="skin-perfume">`
  (آخر طبقة): `--bg-base:#f1e8da` · `--blue:#8a6a4a` (اللون الأساسي) · `--gold:#b08d57` · حبر بني `#33271b`.
- المظهر الداكن بني داكن (`#1b1510`) وليس أسود/أزرق.
- تصنيف الموسم: شارة **صيفية** (كهرماني) و**شتوية** (بنفسجي رمادي ناعم).
- بيع التقسيم: صندوق بيج مدمج داخل صف البيع (أزرار 5/10/20/30/50 مل، العبوة، السعر، ملخص الحساب).
- الأيقونات: SVG داخلية (`i-perfume` · `i-drop` · `i-vial` · `i-sun2` · `i-snow`) — بلا اعتماد خارجي.
- الخطوط مضمّنة (base64) فتعمل الواجهة دون اتصال بالإنترنت.
